# SafeSide Insurance Platform

Insurance operations platform designed to manage insurance services, customer requests, claims tracking, and operational workflows.

---

## Features

- Insurance Requests
- Policy Management
- Claims Tracking
- Customer Dashboard
- Agent Management
- Reports & Analytics
- Notifications System
- Multi-user Roles

---

## Tech Stack

- Laravel
- PHP
- MySQL
- TailwindCSS
- REST APIs
